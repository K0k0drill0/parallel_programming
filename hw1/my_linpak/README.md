# LINPACK на C++

Последовательный учебный тест производительности решения системы линейных
уравнений `Ax = b` с плотной матрицей и числами типа `double`. Используется LUP-разложение.

Производительность вычисляется по стандартной оценке числа операций LINPACK:

Далее N - размерность матрицы.
```text
FLOP ≈ (2/3) * N^3 + 2 * N^2
GFLOPS = FLOP / время_в_секундах / 10^9
TFLOPS = FLOP / время_в_секундах / 10^12
```

## Сборка и запуск

```sh
c++ -O3 -std=c++17 -Wall -Wextra -Wpedantic linpack.cpp -o linpack
./linpack 1000
```

Аргумент `1000` — размер матрицы `N`; без аргумента используется `N = 1000`.
Программа однопоточная!
